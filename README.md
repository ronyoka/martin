# Martin tanulós oldalai

Kétnyelvű (spanyol/angol – magyar) interaktív gyakorló oldalak egy 3. osztályos tanulónak.

- `index.html` – nyitóoldal, innen lehet tantárgyat választani
- `matematicas/`, `lengua/`, `english/`, `sociales/`, `natural/`, `arts/` – a tantárgyak önálló oldalai a hangfájlokkal
- `forras/` – a generátor forrása (tartalom, szótár, párbeszédek, eszközök)

Az oldalak GitHub Pages-en futnak, telepítés nélkül.
